# D11 — FFT and Precise Sinusoid Measurement (complete)

Status: implemented · 229/229 on MSVC Release+Debug, UCRT64 GCC
Release+Debug, GCC-13 Release+Debug, Clang-18 Release+Debug, GCC ASan+UBSan
(zero reports, 17 examples clean) · Probes: 10/10

The measuring instrument step 3 needed. Pitch and decay error of the
solvers cannot be claimed without measuring rendered output, and no spectral
tool existed. Scope is deliberately narrow: a transform, windows, and one
precise sinusoid estimator. Short-time analysis, peak picking across many
partials and noise statistics belong to the later analysis milestone.

## New code

| Header | Contents |
|---|---|
| `analysis/fft.h` | `fft`/`ifft` (iterative radix-2, power-of-two lengths, 1/N on the inverse); `windowCoefficients` (periodic Rectangular, Hann, 4-term Blackman-Harris per Harris 1978); `estimateSinusoid` (frequency, amplitude, phase of the strongest sinusoid in a search band) |

## Method

- **Transform**: X[k] = Σₙ x[n]·e^(−2πikn/N). Butterflies use direct
  trigonometry per index, so there is no accumulated rotation drift.
- **Estimator**:
  1. Coarse peak: the largest windowed-FFT bin inside the band.
  2. Refinement: the stationary point of |X(f)|², found by **bisection on
     the sign of d|X|²/df = 2·Re(X̄·X′)**, with
     X′ = Σ w·x·(−2πin/fs)·e^(−2πifn/fs). The bracket is ±(halfLobe − ½)
     bins, inside the main-lobe nulls.
  3. Amplitude = 2|X(f)|/Σw; phase is referenced to sample 0.
- **Rejections (`DomainError`)**:
  - No interior stationary point (the slope doesn't change sign).
  - Failed main-lobe check: the magnitude at ±halfLobe bins from the
    peak must be below −60 dB (Blackman-Harris), −20 dB (Hann) or −6 dB
    (rectangular). Otherwise the maximum is a sidelobe ripple, or several
    components sit inside one main lobe.

## Evidence

- **FFT vs a naive O(N²) DFT** written in the test (N = 1…512): ≤ 1e-11.
- **Identities**: an impulse gives exactly all-ones; a constant gives N at
  DC (≤ 1e-12 elsewhere); the round trip is ≤ 1e-13; Parseval holds to
  1e-12 relative.
- **Periodic window sums**: exactly a₀·N (Hann N/2, Blackman-Harris
  0.35875·N) to 1e-9.
- **Single tone** 440.123456789 Hz, amplitude 0.7, phase 0.4 (Blackman-Harris):
  - Frequency error: **7.0e-7 Hz at N = 8192**, **1.1e-7 Hz at N = 65536**.
  - Amplitude: 1e-6 relative. Phase: 1e-5.
  - Asserted: the error improves with N and stays below 1e-5 cents.
- **Two equal tones 13.7 bins apart** (440 and 480 Hz): each is measured
  within 3.1e-5 Hz.
- **Rejections**:
  - A band containing no tone: all three windows refuse.
  - Two tones inside one main lobe: refused.
  - Too few samples, a band above Nyquist, or silence: rejected.

## Caught during implementation

1. **False peaks**: before the main-lobe check existed, a band with no
   tone returned a sidelobe ripple as a "sinusoid" (the test
   expected `DomainError` and got success). The check was added and is now
   tested on all three windows.
2. **Precision limited by the method, not the data**: a golden-section
   maximization of |X(f)| on its flat top resolved frequency only to about
   √ε of the lobe width. It measured 8.6e-7 Hz against a 1e-6 Hz test, too
   close to be robust across compilers. It was replaced by bisection on the
   derivative's sign, which reaches machine resolution.
3. **A sign error in the derivative**: the first slope formula negated
   twice (a negative scale times (−sin θ, −cos θ)), so every estimate was
   rejected. It was re-derived by hand, (−i)·e^(−iθ) = −sin θ − i·cos θ, and
   fixed. The bracket was also moved half a bin inside the main-lobe
   nulls, where the slope's sign is roundoff.
4. **A hypothesis not confirmed, so not claimed**: the residual error was
   attributed to leakage from the tone's own negative-frequency image.
   That predicts a ≥ 10× drop from N = 8192 to 65536; the measured drop was
   about 6×. The source of the residual is therefore stated as not
   isolated. Only its size is asserted, and it is over 1000× finer than
   the pitch errors D12 measures.
