# Christmas (public domain)

Scores for the winds harness (tools/demo/winds_pro1/wp1, env WP_SONGFILE=<txt>), written by make_songs.py with the sources in its header:

- Silent Night (Gruber 1818): Mutopia GruberFX/stille_nacht hymntune (Public Domain, from cyberhymnal.org), soprano on flute, alto on clarinet, up a whole tone to C.
- Jingle Bells (Pierpont): verse from the 1857 facsimile (Project Gutenberg #10535), refrain from Wikimedia Commons File:Jingle_Bells_refrain_vector.svg (PD). Trumpet melody, sleigh bells from jingle_sleigh_timeline.txt (tools/demo/sleigh_bells/sbpat).

Only public-domain material lives here. Copyrighted arrangements are rendered locally and are not committed.
